# 🗣️ Japanese Useful Phrases Cheat Sheet

| Japanese | English | Notes |
|:---------|:--------|:------|
| こんにちは (Konnichiwa) | Hello / Good afternoon | Until sunset. |
| おはよう (Ohayou) | Good morning | Informal. |
| おはようございます (Ohayou gozaimasu) | Good morning (polite) | Formal version. |
| こんばんは (Konbanwa) | Good evening | |
| さようなら (Sayounara) | Goodbye | More formal / final. |
| またね (Mata ne) | See you later | Informal. |
| ありがとう (Arigatou) | Thank you | Informal. |
| ありがとうございます (Arigatou gozaimasu) | Thank you (polite) | Formal. |
| すみません (Sumimasen) | Excuse me / Sorry | Also used to get attention. |
| ごめんなさい (Gomen nasai) | I’m sorry | Apologizing. |
| はい (Hai) | Yes | |
| いいえ (Iie) | No | |
| おねがいします (Onegaishimasu) | Please | Polite request. |
| どうぞ (Douzo) | Here you go | Offering something. |
| わかります (Wakarimasu) | I understand | |
| わかりません (Wakarimasen) | I don’t understand | |
| えいごをはなせますか？ (Eigo wo hanasemasu ka?) | Can you speak English? | "Eigo" = English language. |
| にほんごがわかりません (Nihongo ga wakarimasen) | I don't understand Japanese | |
| だいじょうぶ (Daijoubu) | It’s okay / I’m fine | |
| いくらですか？ (Ikura desu ka?) | How much is it? | |
| どこですか？ (Doko desu ka?) | Where is it? | Add place names (ex: "toilet"). |
| トイレはどこですか？ (Toire wa doko desu ka?) | Where is the toilet? | |
| たすけて！ (Tasukete!) | Help! | Emergency. |

---

# 🛎 Bonus Quick Tips

- **Desu (です)** = polite "is/am/are" — makes things more polite.
- **Ka (か)** at the end makes it a **question**.
- **Polite speaking tip:** Just adding **"onegaishimasu"** to a word sounds polite!
