# 🍣 Japanese Food Cheat Sheet

| Japanese Word        | English Meaning           | Notes                                       |
| :------------------- | :------------------------ | :------------------------------------------ |
| ごはん (Gohan)          | Rice / Meal               | "Gohan" can mean just rice or a whole meal. |
| みず (Mizu)            | Water                     | Asking for water: "Mizu onegaishimasu"      |
| おちゃ (Ocha)           | Tea (usually green)       |                                             |
| にく (Niku)            | Meat                      | Beef, chicken, pork = see below             |
| ぎゅうにく (Gyuuniku)     | Beef                      | "Gyu" = cow                                 |
| とりにく (Toriniku)      | Chicken                   | "Tori" = bird                               |
| ぶたにく (Butaniku)      | Pork                      | "Buta" = pig                                |
| さかな (Sakana)         | Fish                      |                                             |
| いか (Ika)             | Squid                     | Often served raw, grilled, or fried.        |
| たこ (Tako)            | Octopus                   | Used in sushi and takoyaki.                 |
| うなぎ (Unagi)          | Freshwater eel            | Often grilled with sweet soy sauce.         |
| ぎゅうたん (Gyūtan)       | Beef tongue               | Specialty in Sendai, grilled slices.        |
| すし (Sushi)           | Vinegared rice + raw fish |                                             |
| さしみ (Sashimi)        | Sliced raw fish (no rice) |                                             |
| らーめん (Ramen)         | Noodle soup               |                                             |
| うどん (Udon)           | Thick wheat noodles       |                                             |
| そば (Soba)            | Buckwheat noodles         | Often served cold or hot.                   |
| てんぷら (Tempura)       | Fried seafood/vegetables  | Light, crispy batter.                       |
| やきとり (Yakitori)      | Grilled chicken skewers   |                                             |
| たこやき (Takoyaki)      | Fried octopus balls       | Street food favorite.                       |
| おこのみやき (Okonomiyaki) | Savory pancake            | Cabbage, meat, seafood inside.              |
| べんとう (Bento)         | Boxed meal                |                                             |
| なっとう (Nattō)         | Fermented soybeans        | Very strong smell/taste!                    |
| みそしる (Miso Shiru)    | Miso soup                 |                                             |
| からあげ (Karaage)       | Fried chicken             | Juicy and crispy!                           |
| ぎょうざ (Gyoza)         | Dumplings                 | Pan-fried.                                  |
| かれー (Karee)          | Japanese curry            | Heavier and sweeter than Indian curry.      |
| もも (Momo)            | Peach                     | Popular in summer.                          |
| ばなな (Banana)         | Banana                    | Common snack/dessert.                       |
| とまと (Tomato)         | Tomato                    | Often eaten fresh or in salads.             |
| りんご (Ringo)          | Apple                     |                                             |
| ぶどう (Budō)           | Grapes                    | Japanese varieties are large and sweet.     |
| あまい (Amai)           | Sweet                     |                                             |
| からい (Karai)          | Spicy                     |                                             |
| しお (Shio)            | Salt                      |                                             |
| しょうゆ (Shouyu)        | Soy sauce                 |                                             |

# 🛎 Useful Phrases

- **〜をください (~ wo kudasai)** = Please give me ~  
  Ex: *Rāmen wo kudasai* → "Ramen, please."

- **おいしい！ (Oishii!)** = Delicious!

- **おすすめは？ (Osusume wa?)** = What's your recommendation?

- **これください (Kore kudasai)** = I’ll take this (pointing at menu).
