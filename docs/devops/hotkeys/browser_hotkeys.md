## Hotkeys for Browsers

These work in:
* Google Chrome
* Brave
* Microsoft Edge
* Mozilla Firefox

---

## TAB MANAGEMENT

New tab
Ctrl + T

Close current tab
Ctrl + W

Reopen last closed tab
Ctrl + Shift + T

Next tab
Ctrl + Tab

Previous tab
Ctrl + Shift + Tab

Go to tab number (1–8)
Ctrl + 1–8

Go to last tab
Ctrl + 9

Duplicate tab
Ctrl + L → Alt + Enter

---

## WINDOW MANAGEMENT

New window
Ctrl + N

New private/incognito window
Ctrl + Shift + N  (Chrome/Brave/Edge)
Ctrl + Shift + P  (Firefox)

Close window
Ctrl + Shift + W

---

## NAVIGATION

Back
Alt + Left Arrow

Forward
Alt + Right Arrow

Reload
Ctrl + R

Hard reload
Ctrl + Shift + R

Stop loading
Esc

Home
Alt + Home

---

## ADDRESS BAR

Focus address bar
Ctrl + L
Alt + D
F6

Open typed URL in new tab
Alt + Enter

Add [www](http://www). + .com
Ctrl + Enter

Search from address bar
Ctrl + K

---

## PAGE CONTROLS

Find on page
Ctrl + F

Find next
Enter

Find previous
Shift + Enter

Zoom in
Ctrl + +

Zoom out
Ctrl + -

Reset zoom
Ctrl + 0

Full screen
F11

Print
Ctrl + P

Save page
Ctrl + S

View page source
Ctrl + U

Open DevTools
Ctrl + Shift + I

---

## BOOKMARKS

Bookmark page
Ctrl + D

Open bookmarks manager
Ctrl + Shift + O

Show/hide bookmarks bar
Ctrl + Shift + B

---

## DOWNLOADS & HISTORY

Downloads
Ctrl + J

History
Ctrl + H

Clear browsing data
Ctrl + Shift + Delete
