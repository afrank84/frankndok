# How to Add or Edit Priorities in Jira

To **edit existing priorities or create new ones** in Jira:

1. Click the **gear icon (Settings)** in the top-right corner.
2. Select **Work items** (called **Issues** in older Jira versions).
3. Under **Work item attributes**, select **Priorities**.
4. From there, you can:
   - **Add priority** — Create a new priority with a name, description, and color.
   - **Edit** — Change an existing priority.
   - **Delete** — Remove a priority you no longer need.
   - **Reorder** — Change the priority ranking.

## Direct Link for Jira Cloud

Replace `YOUR-DOMAIN` with your Jira domain:

`https://YOUR-DOMAIN.atlassian.net/secure/admin/ViewPriorities.jspa`

## Important Notes

- **Permissions:** You need Jira administrator permissions to manage priorities.
- **Priority Schemes:** New priorities may need to be added to your project's **Priority Scheme** before they appear in issues.
